내가 필요해서 만든 바탕화면 캘린더 - 개인정보 처리방침

시행일: 2026년 11월 1일

1. 모으는 정보

내가 필요해서 만든 바탕화면 캘린더(MyCalendar, 이하 "앱")는 개발자가 운영하는 서버가 없으며, 사용자의 정보를 개발자에게 보내거나 모으지 않습니다. 앱에 적은 일정, 메모, 스티커 메모, 설정은 모두 사용자의 PC(%AppData%\MyCalendar 폴더)에만 저장됩니다.

2. 사용자가 직접 연결한 서비스와의 통신

사용자가 환경설정에서 직접 켜거나 연결한 경우에만, 앱이 아래 서비스와 직접 통신합니다. 이때 오가는 정보는 해당 서비스의 개인정보 처리방침을 따릅니다.

  • 구글 캘린더 / 구글 Tasks - 사용자가 만든 클라이언트 ID로 로그인한 경우, 일정과 할 일을 주고받습니다.
  • Outlook / Microsoft 365, CalDAV(iCloud, 네이버 등) 계정 - 사용자가 추가한 계정의 일정을 주고받습니다.
  • 캘린더 구독 - 사용자가 넣은 .ics 주소에서 일정을 받아 옵니다.
  • 여러 PC 동기화 - 사용자가 고른 폴더(클라우드 드라이브 등)에 스티커 메모와 설정을 저장합니다.
  • 지도 - "지도" 단추를 누르면 고른 지도 서비스(네이버/카카오/구글) 웹 페이지를 엽니다.

마이크로소프트 스토어가 아닌 설치 파일(zip)로 설치한 경우에만, 새 버전이 있는지 GitHub(github.com)에 확인합니다. 이때 개인 정보는 보내지 않습니다. 스토어에서 설치한 앱은 스토어가 업데이트를 맡아 이 확인을 하지 않습니다.

로그인 정보(토큰)와 계정 암호는 사용자 PC에만 저장되며, 계정 암호는 Windows 보호 기능(DPAPI)으로 암호화합니다.

3. 제3자 제공·광고·분석

앱은 광고, 사용 통계 수집, 분석 도구를 쓰지 않으며 어떤 정보도 제3자에게 제공하지 않습니다.

4. 정보 지우기

앱 안에서 일정과 계정을 지울 수 있고, %AppData%\MyCalendar 폴더를 지우면 앱이 저장한 모든 정보가 사라집니다. 연결한 서비스의 권한은 각 서비스의 계정 설정에서 해제할 수 있습니다.
