# MyCalendar

내가 쓰려고 만든 데스크톱 캘린더 위젯이다. 바탕화면 위에 항상 떠 있으면서도 다른 창들보다는
항상 뒤에 깔려서, 작업을 방해하지 않으면서 날짜와 일정을 바로바로 확인할 수 있게 만들었다.

![바탕화면에 떠 있는 MyCalendar 전체 화면 이미지](png/%EB%B0%94%ED%83%95%ED%99%94%EB%A9%B4%EC%97%90%20%EB%96%A0%20%EC%9E%88%EB%8A%94%20MyCalendar%20%EC%A0%84%EC%B2%B4%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

## 주요 기능

### 달력 스타일 4종
- **변동 월 / 고정 월**: 흔히 보는 월간 달력 형태.

![변동 월 스타일 화면 이미지](png/%EB%B3%80%EB%8F%99%20%EC%9B%94%20%EC%8A%A4%ED%83%80%EC%9D%BC%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

- **변동 주 / 고정 주**: 한 주를 0~23시 시간표로 펼쳐서 보여준다(구글 캘린더의 "주" 보기와
  비슷한 느낌).

![24시간 시간표(변동 주) 스타일 화면 이미지](png/24%EC%8B%9C%EA%B0%84%20%EC%8B%9C%EA%B0%84%ED%91%9C%28%EB%B3%80%EB%8F%99%20%EC%A3%BC%29%20%EC%8A%A4%ED%83%80%EC%9D%BC%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

### 메모(일정)
- 날짜 칸을 더블클릭하면 메모를 추가할 수 있다. 종일 메모와 시작·종료 시간이 있는 메모를
  둘 다 지원한다.
- 색상을 지정할 수 있고, 이 색은 구글 캘린더의 이벤트 색상과 동일한 팔레트를 쓴다.
- 기존 메모의 글자를 클릭하면 삭제 후 재생성이 아니라 그 메모를 그대로 고칠 수 있다.

![메모 추가/편집 창 이미지](png/%EB%A9%94%EB%AA%A8%20%EC%B6%94%EA%B0%80%2C%20%ED%8E%B8%EC%A7%91%20%EC%B0%BD%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

### 날짜 칸 다중 선택 + 복사·붙여넣기
- 탐색기처럼 클릭/Ctrl+클릭/Shift+클릭/드래그로 여러 날짜를 한 번에 선택할 수 있다.
- 선택한 날짜들의 메모를 Ctrl+C로 복사하고, 다른 날짜를 선택한 뒤 Ctrl+V로 붙여넣으면
  선택했던 첫 날짜를 기준으로 한 날짜 간격을 그대로 유지한 채 메모가 복제된다(예: 월~토
  6일치를 복사해서 다음 주 화요일에 붙여넣으면 각 메모가 정확히 같은 요일 간격으로 옮겨진다).

![여러 날짜를 드래그로 선택한 화면 이미지](png/%EC%97%AC%EB%9F%AC%20%EB%82%A0%EC%A7%9C%EB%A5%BC%20%EB%93%9C%EB%9E%98%EA%B7%B8%EB%A1%9C%20%EC%84%A0%ED%83%9D%ED%95%9C%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

### 그 외
- 음력 날짜, 공휴일(양력 고정 공휴일 + 음력 명절) 자동 표시.
- 메모에 등록한 시간이 되면 알림(풍선 알림 + 알람음).
- 글꼴(캘린더/메모 각각), 색상, 배경(이미지 포함), 셀 간격 등 화면 요소를 세세하게 커스터마이징
  가능.
- Windows 시작프로그램 등록 지원 - 컴퓨터를 켜면 자동으로 실행되게 할 수 있다.

![환경설정 화면 이미지](png/%ED%99%98%EA%B2%BD%EC%84%A4%EC%A0%95%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

## 구글 캘린더 연동

이 앱은 구글 캘린더와 양방향으로 동기화할 수 있다(이 앱에서 쓴 메모가 구글 캘린더에도 올라가고,
구글 캘린더에서 만든 일정도 이 앱에 반영됨). 다만 앱 자체에 구글 인증 정보가 내장돼 있지 않아서,
사용하려면 구글 클라우드 콘솔에서 본인 명의의 OAuth 클라이언트를 직접 만들어 등록해야 한다.
아래 순서대로 하면 된다.

### 1. 구글 클라우드 콘솔에서 프로젝트 만들기

![구글 클라우드 콘솔 새 프로젝트 만들기 화면 이미지](png/%EA%B5%AC%EA%B8%80%20%ED%81%B4%EB%9D%BC%EC%9A%B0%EB%93%9C%20%EC%BD%98%EC%86%94%20%EC%83%88%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

1. https://console.cloud.google.com/ 접속 후 로그인한다.
2. 새 프로젝트를 하나 만든다(이미 쓰던 프로젝트가 있다면 그걸 써도 된다).

### 2. Google Calendar API 사용 설정

![API 및 서비스 > 라이브러리에서 Google Calendar API를 찾아 사용 설정하는 화면 이미지](png/API%20%EB%B0%8F%20%EC%84%9C%EB%B9%84%EC%8A%A4%20-%20%EB%9D%BC%EC%9D%B4%EB%B8%8C%EB%9F%AC%EB%A6%AC%EC%97%90%EC%84%9C%20Google%20Calendar%20API%EB%A5%BC%20%EC%B0%BE%EC%95%84%20%EC%82%AC%EC%9A%A9%20%EC%84%A4%EC%A0%95%ED%95%98%EB%8A%94%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

1. 좌측 메뉴에서 **API 및 서비스 > 라이브러리**로 이동한다.
2. "Google Calendar API"를 검색해서 들어간 뒤 **사용 설정**을 누른다.

### 3. OAuth 동의 화면 설정

![OAuth 동의 화면 설정 이미지](png/OAuth%20%EB%8F%99%EC%9D%98%20%ED%99%94%EB%A9%B4%20%EC%84%A4%EC%A0%95%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

1. **API 및 서비스 > OAuth 동의 화면**으로 이동한다.
2. User Type은 **외부(External)** 를 선택한다(개인적으로 혼자 쓸 용도라 앱을 구글의 별도
   심사에 제출할 필요는 없다 - "테스트" 상태로 둬도 충분하다).
3. 앱 이름, 지원 이메일 등 필수 항목만 채워서 저장한다.
4. **테스트 사용자** 항목에 본인 구글 계정 이메일을 추가해 둔다(테스트 상태인 앱은 여기 등록된
   계정으로만 로그인이 허용된다).

### 4. OAuth 클라이언트 ID 만들기

![사용자 인증 정보 만들기 > OAuth 클라이언트 ID, 애플리케이션 유형을 데스크톱 앱으로 선택하는 화면 이미지](png/%EC%82%AC%EC%9A%A9%EC%9E%90%20%EC%9D%B8%EC%A6%9D%20%EC%A0%95%EB%B3%B4%20%EB%A7%8C%EB%93%A4%EA%B8%B0%20-%20OAuth%20%ED%81%B4%EB%9D%BC%EC%9D%B4%EC%96%B8%ED%8A%B8%20ID%2C%20%EC%95%A0%ED%94%8C%EB%A6%AC%EC%BC%80%EC%9D%B4%EC%85%98%20%EC%9C%A0%ED%98%95%EC%9D%84%20%EB%8D%B0%EC%8A%A4%ED%81%AC%ED%86%B1%20%EC%95%B1%EC%9C%BC%EB%A1%9C%20%EC%84%A0%ED%83%9D%ED%95%98%EB%8A%94%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

1. **API 및 서비스 > 사용자 인증 정보**로 이동한다.
2. **사용자 인증 정보 만들기 > OAuth 클라이언트 ID**를 선택한다.
3. 애플리케이션 유형은 반드시 **데스크톱 앱**으로 선택한다.
4. 만들고 나면 **클라이언트 ID**와 **클라이언트 보안 비밀**이 발급된다.

![발급된 클라이언트 ID/보안 비밀 화면 이미지](png/%EB%B0%9C%EA%B8%89%EB%90%9C%20%ED%81%B4%EB%9D%BC%EC%9D%B4%EC%96%B8%ED%8A%B8%20ID%2C%20%EB%B3%B4%EC%95%88%20%EB%B9%84%EB%B0%80%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

### 5. 앱 정보 등록하기

![API 및 서비스 - Google 인증 플랫폼 - 브랜딩](png/API%20%EB%B0%8F%20%EC%84%9C%EB%B9%84%EC%8A%A4%20-%20Google%20%EC%9D%B8%EC%A6%9D%20%ED%94%8C%EB%9E%AB%ED%8F%BC%20-%20%EB%B8%8C%EB%9E%9C%EB%94%A9.png)

1. **앱 이름 > MyCalendar**를 입력한다.
2. **사용자 지원 이메일 > 본인 구글 이메일**인지 확인한다.
3. 아래에 있는 **개발자 연락처 정보 > 본인 구글 이메일**인지 확인한다.

※ 해당 설정을 하지 않으면 **OAuth 로그인에서 앱 인증 문제가 발생**한다.

### 6. OAuth 로그인 가능 권한 설정

![API 및 서비스 - Google 인증 플랫폼 - 대상](png/API%20%EB%B0%8F%20%EC%84%9C%EB%B9%84%EC%8A%A4%20-%20Google%20%EC%9D%B8%EC%A6%9D%20%ED%94%8C%EB%9E%AB%ED%8F%BC%20-%20%EB%8C%80%EC%83%81.png)

1. **테스트 사용자 > Add users > 본인 구글 이메일**을 추가한다.
2. 여기서 **다른 이메일을 추가하면 다른 이메일도 같은 OAuth로 로그인이 가능**하다.

※ **일일 사용량 100만회**를 넘을 수 없다.

### 7. MyCalendar에 등록하기

![MyCalendar 환경설정 > 구글 캘린더 탭 이미지](png/MyCalendar%20%ED%99%98%EA%B2%BD%EC%84%A4%EC%A0%95%20-%20%EA%B5%AC%EA%B8%80%20%EC%BA%98%EB%A6%B0%EB%8D%94%20%ED%83%AD%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

1. MyCalendar의 ☰ 메뉴 > **환경설정**을 연다.
2. 좌측 분류에서 **구글 캘린더**를 선택한다.
3. 방금 발급받은 **클라이언트 ID**와 **클라이언트 보안 비밀**을 각각 입력란에 붙여넣는다.
4. **연결** 버튼을 누르면 기본 브라우저가 열리면서 구글 로그인/권한 동의 화면이 뜬다. 로그인을
   마치면 앱으로 돌아와서 계정이 연결된 상태로 표시된다.
5. **양방향 동기화** 스위치를 켠다. 이후로는 5분마다 자동으로 동기화되며, **지금 동기화** 버튼을
   눌러 바로 동기화할 수도 있다.

![연결 완료 후 계정 정보와 동기화 상태가 표시된 화면 이미지](png/%EC%97%B0%EA%B2%B0%20%EC%99%84%EB%A3%8C%20%ED%9B%84%20%EA%B3%84%EC%A0%95%20%EC%A0%95%EB%B3%B4%EC%99%80%20%EB%8F%99%EA%B8%B0%ED%99%94%20%EC%83%81%ED%83%9C%EA%B0%80%20%ED%91%9C%EC%8B%9C%EB%90%9C%20%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%AF%B8%EC%A7%80.png)

### 참고

- 클라이언트 ID/보안 비밀은 컴퓨터 안(`%AppData%/MyCalendar/settings.json`)에만 저장되며,
  어디로도 전송되지 않는다.
- 로그인 정보(토큰)는 `%AppData%/MyCalendar/google_token_cache` 폴더에 저장된다. **연결 해제**를
  누르면 이 캐시가 삭제되어 다시 로그인해야 한다.
- 반복 일정(매주/매달 반복 등)은 아직 지원하지 않는다. 동기화 시 반복 일정은 건너뛴다.
